# Farheen Fatima — Portfolio

**Live site:** [farheen-fatima-portfolio.vercel.app](https://farheen-fatima-portfolio.vercel.app)

A responsive, dark-themed personal portfolio showcasing my AI, Machine Learning, Data Science and Automation projects. Hand-coded with vanilla HTML, CSS and JavaScript — no frameworks.

## Features

- Animated particle-network hero section
- Skills organized across 6 categories
- Project cards with links to live demos and source code
- Education timeline, certifications and contact sections
- Sticky navbar with scroll blur and scroll-triggered reveal animations
- Mobile hamburger menu and keyboard-accessible focus states

## Tech Stack

HTML · CSS · JavaScript · Deployed on **Vercel** with automatic deployment on every push to `main`

## Run Locally

```bash
git clone https://github.com/farheenfatima110/farheen-fatima-portfolio.git
cd farheen-fatima-portfolio
# open index.html in your browser
```
